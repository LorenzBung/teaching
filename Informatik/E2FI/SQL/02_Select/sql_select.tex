	\begin{hint}{Aufbau einer Datenabfrage in SQL}
		Eine der wichtigsten Funktionen von Datenbanken ist das Auslesen von Daten.
		In SQL besteht der Befehl zur Abfrage von Datensätzen aus drei Bestandteilen:
		\begin{itemize}
			\item \texttt{SELECT}: zuerst werden die Tabellenspalten angegeben, die ausgelesen werden sollen. Ein \texttt{*} wählt dabei alle Spalten aus.
			\item \texttt{FROM}: es muss ausgewählt werden, aus welcher Tabelle die Daten stammen.
			\item \texttt{WHERE}: zuletzt können Einschränkungen gemacht werden, so dass nur bestimmte Datensätze ausgegeben werden.
		\end{itemize}
	\end{hint}
	
	Eine typische Abfrage sähe beispielsweise folgendermaßen aus:
	
	\begin{lstlisting}[language=sql]
SELECT Name FROM Kunde WHERE GebDatum < '1980-01-01';
	\end{lstlisting}
	
	Der Befehl gibt die Namen aller Kunden aus, welche vor dem 01.01.1980 geboren sind.
	
	\begin{warning}{Vergleichs- und Logikoperatoren in SQL}
		In \texttt{WHERE}-Einschränkungen können die Vergleichsoperatoren \texttt{=}, \texttt{<}, \texttt{>}, \texttt{<=}, \texttt{>=} und \texttt{<>} verwendet werden.
		Wesentliche Unterschiede im Vergleich zu typischen Programmiersprachen wie Python sind der Vergleich mit \texttt{=} (statt \texttt{==}) und der Vergleich auf Ungleichheit mit \texttt{<>} (statt \texttt{!=}).
		
		Zusätzlich können mehrere Bedingungen mit den Keywords \texttt{AND}, \texttt{OR} und \texttt{NOT} (sowie angemessener Klammerung) verknüpft werden.
	\end{warning}
	
	\begin{hint}{Komplexere Vergleiche}
		Die Vergleiche können noch komplexer gestaltet werden, indem man den \texttt{LIKE}-Operator verwendet.
		Das Zeichen \texttt{\%} steht dabei für eine beliebige Zeichenkette, während das Zeichen \texttt{\_} einen einzelnen Charakter darstellt.
		
		Außerdem kann man mit \texttt{BETWEEN} überprüfen, ob ein Wert in einem bestimmten Bereich liegt.
		Der Operator \texttt{IN} überprüft, ob der gesuchte Wert in einer Liste ist.
		Die Liste wird mit kommagetrennten Werten in runden Klammern angegeben.
	\end{hint}
	
	\pagebreak
	
	Komplexere Vergleiche könnten beispielsweise so aussehen:
	
	\begin{lstlisting}[language=sql]
SELECT GebDatum FROM Kunde WHERE Name LIKE 'Max%';
SELECT * FROM Bestellung WHERE Preis BETWEEN 100 AND 1000;
SELECT Adresse FROM Kunde WHERE Name IN ('Max', 'Mia', 'Moritz')
	\end{lstlisting}
	
	Der erste Befehl gibt die Geburtstage aller Kunden aus, deren Name mit 'Max' beginnt.
	Der zweite Befehl gibt alle Bestellungen aus, deren Preis zwischen 100 und 1000 liegt.
	Der dritte Befehl gibt die Adressen aller Kunden aus, die 'Max', 'Mia' oder 'Moritz' heißen.

	\begin{hint}{Bundesliga-Datenbank}
		Im Schulnetzwerk steht die PostgreSQL-Datenbank \texttt{bundesliga} zur Verfügung, die Daten über die vergangene Saison beinhaltet.
		
		Mit dem folgenden Befehl und dem Passwort \texttt{postgres} kann man sich im Schulnetzwerk auf die Datenbank verbinden:
		
		\begin{lstlisting}[numbers=none]
psql -h localhost bundesliga postgres
		\end{lstlisting}
		
		Die Bundesliga-Datenbank beinhaltet folgende Tabellen:
		
%		\texttt{verein(\underline{vid}, name, liga)}
%		
%		\texttt{spiel(\underline{nr}, spieltag, datum, anstoss, \dashuline{heim}, \dashuline{gast}, tore\_heim, tore\_gast, zuschauer, schiedsrichter)}
%		
%		\texttt{spieler(\underline{sid}, \dashuline{verein}, nachname, vorname, geburtsdatum, land, position, spiele, tore)}
		\begin{lstlisting}[numbers=none, frame=none, escapechar=§]
verein(§\underline{vid}§, name, liga)
spiel(§\underline{nr}§, spieltag, datum, anstoss, §\dashuline{heim}§, §\dashuline{gast}§, tore_heim, tore_gast, zuschauer, schiedsrichter)
spieler(§\underline{sid}§, §\dashuline{verein}§, nachname, vorname, geburtsdatum, land, position, spiele, tore)
		\end{lstlisting}
		
		Die unterstrichenen Attribute sind Primärschlüssel, gestrichelt unterstrichene Attribute sind Fremdschlüssel.
	\end{hint}
	
	
	\task{Abfragen auf der Bundesliga-Datenbank}
	
	Verbinden Sie sich auf die Bundesliga-Datenbank und finden Sie die folgenden Daten.
	Notieren Sie jeweils den dazu verwendeten SQL-Befehl.
	
	\begin{enumerate}[label=\alph*)]
		\item Geben Sie alle Spieler aus.
		\item Geben Sie die Namen aller Vereine aus.
		\item Geben Sie die Namen aller Spieler aus, die ``Thomas'' heißen.
		\item Geben Sie die Spieltage aller Spiele aus, die mehr als 30000 Zuschauer hatten und bei denen die Gastmannschaft genau ein Tor geschossen hat.
		\item Finden Sie zuerst die Vereinsnummer des SC Freiburg heraus.
		Geben Sie dann die Namen aller Spieler aus, die beim SC Freiburg spielen.
		\item Geben Sie alle Spiele aus, die nach 19:00 Uhr begonnen haben.
		\item Geben Sie alle Spiele aus, bei denen die Heimmannschaft gewonnen hat.
		\item Geben Sie alle Vereine aus, deren Name ``Berlin'' beinhaltet.
		\item Geben Sie alle Spiele aus, die am 1., 17. oder 33. Spieltag stattgefunden haben.
		\item Geben Sie alle Spiele aus, die zwischen dem 18. und dem 34. Spieltag stattgefunden haben.
		\item Geben Sie alle Spiele aus, die im Februar stattgefunden haben.
	\end{enumerate}
